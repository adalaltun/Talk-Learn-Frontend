  Talk&Learn is an app aiming to bring language learners together. The main reason people suffer from
slow pacing when learning a new language is due to the lack of everyday speaking. Communicating with
native speakers is a great way to address this problem although contacting them can become a challenge.
The app aims to solve this problem by creating a bridge between learners and proficient speakers in a
systematic way that will create regular time intervals for communication.
  Users can meet each other with the built in rendezvous system. They can also chat with each other
through the app and withdraw before the meet up. Users can rate their meeting and contribute to the trust
score of the proficient user. Proficient users can specify topics they want to discuss from a list of various
subjects when posting an ad; users can filter ads to see those containing specific topics they are interested in.
